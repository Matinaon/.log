# .log — archivo de arquitecturas desaparecidas

Sitio estático (HTML + JS). Para publicarlo con GitHub Pages:
1. Subí todos estos archivos a un repositorio nuevo (Add file → Upload files).
2. Settings → Pages → Branch: `main` / carpeta `/ (root)` → Save.
3. En un par de minutos queda en `https://<tu-usuario>.github.io/<repo>/`.
